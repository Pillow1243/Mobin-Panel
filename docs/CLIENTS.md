# Mobin Panel — Client Configuration Notes

_Created by Mobin.A_

Minimum client versions and per-client quirks. All exports are generated by
`src/services/configGenerator.ts` and covered by unit tests.

| Client | Export format | Min version | Notes |
| ------ | ------------- | ----------- | ----- |
| v2rayN | JSON array (add-server import) | 7.22.5+ | Entries use `type: vless/trojan`, `network: ws`, `ws-opts.path`, `ws-opts.fragment`, `fingerprint`, `tfo`. Import via *Server → Import → From File / From Clipboard*. WARP is appended as a `wg://` link. |
| v2rayNG | Share links | 2.2.3+ | Standard `vless://` / `trojan://` links (fragment as `fragment=...` query param). |
| MahsaNG | JSON (v2rayn-json) | 16+ | Same JSON shape as v2rayN; MahsaNG also reads `noise` (Warp-PRO noise section) and `AmneziaWG`. |
| Streisand | Share links | 1.6.71+ | Links + trailing WARP `wg://base64#name`. |
| sing-box | JSON config | 1.12.0+ | Typed DNS servers (`local` / `https` / `fakeip`), `inbounds` ws listener, mihomo-style rules translated to sing-box rule format. Local-DNS mode uses `{"type":"local"}` (≥1.12 syntax). |
| husi | Share links | 1.3.2+ | Links + WARP line. |
| Clash Meta / Clash Verge / FLClash | mihomo YAML | Meta ≥ v2.4 / Verge ≥ 1.7.7 | `proxies` (vmess/trojan wireguard), `rules` (sanctions/bypass/block presets + custom), `dns.enhanced-mode: redir-host|fake-ip`, Warp-PRO noise fields. Verge & FLClash consume the same YAML. |
| Stash | mihomo YAML | 2.0+ | Same YAML as Clash Meta (Stash is a Meta fork). |
| Shadowrocket | Share links | 2.2+ | `vless://`/`trojan://` (+`?encryption=none`), TLS via `security=tls`. |
| PassWall | Share links | 2.4+ | Same as Shadowrocket (it's an SR derivative). |
| NekoBox | Share links | 1.5+ | Standard links. |
| Hiddify | Share links + JSON | 1.0+ | Accepts both; links bundle includes WARP `wg://`. |
| Karing | Share links | 1.3+ | Standard links. |
| WireGuard (native) | `.conf` | any | Standard `[Interface]/[Peer]`, `Address 172.16.0.2/32`, `MTU 1280`, deterministic `Reserved` from the keypair, `Endpoint = [2606:4700:4700::1111]:443`. |
| Amnezia VPN | `.conf` | 4.3+ | WG conf + `AmneziaWG = true` + noise comments (`# noise-*`) understood by the Amnezia client. |
| WG Tunnel | `.conf` | 1.4+ | Plain WG conf (same as native). |

## Warp-PRO noise export mapping

| Noise setting (panel) | Exported to |
| --------------------- | ----------- |
| MahsaNG noise | MahsaNG JSON `noise` object (`mode`, `packets`, `count`, `size`, `delay`) |
| Clash/Amnezia noise | mihomo YAML `wireguard` proxy fields (`amnezia`-compatible) + Amnezia WG conf comments |
| v2ray noise list | v2rayN/MahsaNG JSON `out`/noise blocks per entry |

## General client notes

- **Share links carry the panel UUID/password** — treat them like passwords.
- **Subscription URLs carry the subscription key** — rotate it any time from
  Proxy → *Regenerate subscription key* (old links stop working immediately).
- The **private DoH** endpoint (`/doh`) is used by generated configs to resolve
  the panel host before connecting; it is rate-limited (30 req/10 s per IP).
- WebSocket proxying tunnels **HTTP/1.1 requests only** (the reference panel's
  model). For arbitrary TCP/UDP use the WARP export instead — it is a real
  WireGuard tunnel with no per-request overhead on the worker.
